Hardware Projects

A comprehensive showcase of my physical builds and innovations

DIY Spotify Car Thing

Inspired by the Spotify Car Thing, I engineered a compact desk gadget that seamlessly connects to your Spotify account. It features a vibrant LCD display showcasing current song cover art and intuitive haptic buttons for controlling playback – allowing you to rewind, play/pause, skip tracks, and like songs with ease.

Technologies Used
  • ESP8266 Microcontroller
  • LCD Display Module
  • C++ Programming
  • Spotify Web API

MBed Wordle Game

A simple hardware implementation of a Wordle game written in C++, that features an LCD to display animations and game progress, a NAV switch to select letters, mini buttons for tactile inputs, and a speaker for auditory feedback.

Technologies Used
  • C++ Programming
  • mbed LPC1768
  • LCD and NAV Switch
